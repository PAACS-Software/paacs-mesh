# General Tet4 construction qualification

This development round starts from the retained-topology qualification. It
does not schedule a merge or package publication. Kernel decisions must use
geometry, topology, requested controls and measured failure evidence.

1. Cache only repeat refusals with immutable geometric witnesses during initial
   placement. Occupied cells and original facets persist; changing topology,
   external CAD callbacks and resource stops are not interchangeable witnesses.
   Bound storage per active face and compare admitted points with caching off.
2. Locate remaining near-flat cells in the construction stages. Try bounded
   local connectivity changes which preserve coordinates, the oriented cavity
   shell, original source constraints and body ownership. A quality-finalized
   complex is not an unweighted Delaunay certificate. Keep experimental cleanup
   explicit until rollback, cancellation and cross-geometry tests pass.
3. Resolve methods from verified whole-body capabilities before forcing a
   general field route. Explicit modes, spatial controls and historical recipes
   remain authoritative. Expose existing chord and volume-error controls in
   Python and saved recipes. Report requested/effective fidelity and actual
   achieved spacing so different methods can be compared honestly.
4. Reuse frozen identical baselines, then test transformed owned cases, the
   original 51-file corpus and a fixed held-out selection. Record every retry,
   phase work/time, actual counts, quality tails, geometric error and memory.
   Preserve the historical deadline score separately from longer qualification.

The first coverage controls must include both source-boundary failures and
volume-recovery failures. Initial volume improvements alone cannot repair a
nonconforming prescribed surface. Assembly comparisons must distinguish
globally conforming domains from valid independent parts with reported
interference. A change of validation scope is not an algorithmic coverage gain.

Run meaningful timing comparisons serially with one meshing worker and one
validation worker. Larger outputs receive explicit longer time allowances;
measured work and count growth must support any scaling claim. Preserve all
native validity and explicit resource gates.
